# Project Design System

## 适用范围

本技能适用于本项目中涉及视觉设计、页面布局、组件样式、响应式体验、动效或三维内容的任务。

## 设计方向

- 追求具有清晰识别度的设计表达，避免落入通用 SaaS 模板式界面。
- 先建立信息层级、排版节奏、留白与内容优先级，再添加装饰性元素。
- 克制使用圆角卡片、渐变、玻璃拟态和发光效果；仅在能服务内容或品牌表达时采用。
- 动画应自然、简短且有明确反馈目的；避免持续、抢眼或妨碍阅读的动效。

## 响应式与性能

- 优先确保桌面端和移动端的视觉层级、可读性、触控操作与布局稳定性。
- 新增 UI 前先检查现有断点、组件约定和样式方案；以最小改动融入现有系统。
- 如使用 3D 内容，优先评估首屏负载、帧率与交互收益，并提供适合移动端和低性能设备的降级方案。

## 实施与验证

- 不因视觉更新而随意重构无关组件。
- 完成后在目标桌面尺寸和移动尺寸验证视觉与交互；如无法验证，应如实说明。
